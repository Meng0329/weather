### 一、 数据集严格划分与预处理复现规程（Data Pipeline Protocol）

为了保证实验结果 100% 可复现，数据划分直接对齐《气象灾害数据字典》中已有的 5 个按时间切分的数据文件，彻底杜绝未来信息泄露（Data Leakage）：

1. **时序数据集严格切分（Chronological Split）**：
* **训练集（Train Set，2000–2018年）**：合并 `disaster_records_part1_2000-2010.csv`（28,144条）、`disaster_records_part2_2011-2014.csv`（36,417条）与 `disaster_records_part3_2015-2018.csv`（34,302条），共计 **98,863 条**灾情记录及其对应区县的同期地面气象站日值数据。


* **验证集（Validation Set，2019–2021年）**：使用 `disaster_records_part4_2019-2021.csv`，共计 **27,739 条**记录，用于超参数网格搜索与早停（Early Stopping）。


* **测试集（Test Set，2022–2025年）**：使用 `disaster_records_part5_2022-2025.csv`，共计 **24,989 条**记录，仅在最终评估时运行一次。




2. **三大区域基准子集空间过滤规则（Regional Benchmarks）**：
* **SW-Cascade（西南山地灾害链集）**：按 `province`（及气象表 `Province`）筛选 `['云南省', '四川省', '贵州省', '重庆市']`。


* **SE-Typhoon（东南沿海台风洪涝集）**：按 `province` 筛选 `['广东省', '福建省', '浙江省', '海南省', '江苏省']`。


* **North-Agro（北方农业旱涝与强对流集）**：按 `province` 筛选 `['河南省', '山东省', '河北省', '黑龙江省', '吉林省', '辽宁省']`。




3. **气象要素 `99xxxx` 特殊编码与灾情异常值清洗脚本（可直接运行）**：
地面气象要素中包含缺测（`999999`）、不观测（`999998`）、微量（`999990`）、不同降水相态（`9998xx.x`, `9997xx.x`, `9996xx.x`）及仪器上下限极值（`998xxx.x`, `997xxx.x`）等特征值编码；同时灾情表中存在 12 条经济损失超过 10 亿万元的异常值及部分缺失的 `end_time`（填充率 ~80%）和 `county`（填充率 ~70%）。以下代码实现确定性的物理拆解与清洗：



```python
import numpy as np
import pandas as pd

def decode_meteo_features(df_meteo: pd.DataFrame) -> pd.DataFrame:
    """
    可复现的地面气象站特殊特征值(99xxxx)物理相态与极值解耦函数
    输入: 包含 PRS_Avg, WIN_S_Max, TEM_Avg, PRE_Time_2020 等字段的 DataFrame
    """
    df = df_meteo.copy()
    num_cols = [
        'PRS_Avg', 'WIN_S_Max', 'WIN_S_Inst_Max', 'WIN_S_2mi_Avg', 
        'WIN_S_10mi_Avg', 'TEM_Avg', 'TEM_Max', 'TEM_Min', 'PRE_Time_2020'
    ]
    
    # 1. 初始化降水物理相态通道 (针对 PRE_Time_2020)
    # 相态通道: [微量指示, 纯雾露霜(9998), 雨雪混合(9997), 雨夹雪/雪暴(9996)]
    pre = df['PRE_Time_2020'].astype(float)
    df['PRE_phase_trace'] = (pre == 999990.0).astype(np.float32)
    df['PRE_phase_fog_frost'] = ((pre >= 999800.0) & (pre < 999900.0)).astype(np.float32)
    df['PRE_phase_rain_snow'] = ((pre >= 999700.0) & (pre < 999800.0)).astype(np.float32)
    df['PRE_phase_snowstorm'] = ((pre >= 999600.0) & (pre < 999700.0)).astype(np.float32)
    
    # 还原真实降水量数值 xx.x mm
    df.loc[pre == 999990.0, 'PRE_Time_2020'] = 0.05
    for prefix in [999800.0, 999700.0, 999600.0]:
        mask = (pre >= prefix) & (pre < prefix + 100.0)
        df.loc[mask, 'PRE_Time_2020'] = pre[mask] - prefix
    # 24小时自动站统计生成编码 999xxx.x 还原
    mask_auto = (pre >= 999000.0) & (pre < 999600.0)
    df.loc[mask_auto, 'PRE_Time_2020'] = pre[mask_auto] - 999000.0

    # 2. 通用气象要素极值突破与缺测处理
    for col in num_cols:
        val = df[col].astype(float)
        # 缺测(999999)与不观测(999998)转为 NaN，后续用图平流插值
        df.loc[val.isin([999999.0, 999998.0]), col] = np.nan
        
        # 千位为8: >= 仪器上限 (正值, 如 998061.0 -> 61.0)
        mask_upper = (val >= 998000.0) & (val < 999000.0)
        df[f'{col}_exceed_upper'] = mask_upper.astype(np.float32)
        df.loc[mask_upper, col] = val[mask_upper] - 998000.0
        
        # 千位为7: <= 仪器下限 (负值, 如 997026.0 -> -26.0)
        mask_lower = (val >= 997000.0) & (val < 998000.0)
        df[f'{col}_exceed_lower'] = mask_lower.astype(np.float32)
        df.loc[mask_lower, col] = -(val[mask_lower] - 997000.0)
        
        # 本站气压/极值气压 99xxxx.x 还原为 xxxx.x hPa
        if col == 'PRS_Avg':
            mask_prs = (val >= 990000.0) & (val < 997000.0)
            df.loc[mask_prs, col] = val[mask_prs] - 990000.0

    # 按区县时间序列做前向填充与线性插值兜底
    df = df.sort_values(['Province', 'City', 'Cnty', 'Year', 'Mon', 'Day'])
    df[num_cols] = df.groupby(['Province', 'City', 'Cnty'])[num_cols].transform(
        lambda x: x.interpolate(method='linear', limit_direction='both')
    )
    return df

def clean_disaster_records(df_dis: pd.DataFrame) -> pd.DataFrame:
    """
    可复现的灾情直报数据清洗与多阶段报告(初报/续报/终报)事件链重组函数
    """
    df = df_dis.copy()
    # 1. 过滤缺少标准化灾害类型(占1.4%)的无效记录
    df = df[df['disaster_type_std'].notna()].copy()
    
    # 2. 修正 12 条经济损失超过 10亿万元 (1e9万元) 的量纲录入异常 (元误填为万元 -> 除以 1e4)
    abnormal_mask = df['economic_loss'] >= 1e8
    df.loc[abnormal_mask, 'economic_loss'] = df.loc[abnormal_mask, 'economic_loss'] / 10000.0
    
    # 3. 补全缺失的 end_time (~20%缺失): 用 report_time 或 start_time + 类别中位持续时长补齐
    df['start_time'] = pd.to_datetime(df['start_time'])
    df['end_time'] = pd.to_datetime(df['end_time'])
    df['report_time'] = pd.to_datetime(df['report_time'])
    median_duration = (df['end_time'] - df['start_time']).groupby(df['disaster_type_std']).transform('median')
    df['end_time'] = df['end_time'].fillna(df['start_time'] + median_duration).fillna(df['start_time'] + pd.Timedelta(days=1))
    
    # 4. 聚合同一场灾害的“初报 -> 续报 -> 终报”序列
    # 定义同一区县、同一标准灾害类型、起止时间窗口重叠 <= 3天为同一事件链 event_chain_id
    df = df.sort_values(['province', 'city', 'county', 'disaster_type_std', 'start_time', 'report_time'])
    time_diff = (df['start_time'] - df.groupby(['province', 'city', 'county', 'disaster_type_std'])['end_time'].shift(1)).dt.days
    is_new_event = (time_diff.isna()) | (time_diff > 3)
    df['event_chain_id'] = is_new_event.cumsum()
    
    return df

```

### 二、 双层耦合时序知识图谱（Dual-Layer Emergent TKG）构建标准

1. **下层空间基底图 $\mathcal{G}_{\text{spatial}} = (\mathcal{V}_{\text{cnty}}, \mathcal{E}_{\text{adj}})$**：
* **节点 $\mathcal{V}_{\text{cnty}}$**：对齐后的各区县行政单元（`Cnty` / `county`）。每个节点在日期 $t$ 具有 **22 维连续+二值气象特征向量 $\mathbf{x}_{i,t}^{\text{meteo}}$**：包含 9 个常规数值要素（`PRS_Avg`, `WIN_S_Max`, `WIN_S_Inst_Max`, `WIN_S_2mi_Avg`, `WIN_S_10mi_Avg`, `TEM_Avg`, `TEM_Max`, `TEM_Min`, `PRE_Time_2020`）、5 个二值天气现象（`Lit`, `GaWIN`, `Thund`, `Tord`, `Fog`）、4 个降水相态特征（微量、雾露霜、雨雪、雪暴） 及 4 个核心要素破仪器极值指示位。所有连续变量按训练集均值与标准差进行 Z-score 归一化。


* **空间边 $\mathcal{E}_{\text{adj}}$**：若区县 $i$ 与区县 $j$ 共用行政边界或球面距离 $d_{ij} \le 80\text{ km}$，则建立双向有向边 $(i, j)$ 与 $(j, i)$。


2. **上层涌现灾害知识图谱 $\mathcal{G}_{\text{disaster}}(t) = (\mathcal{V}_t, \mathcal{R}, \mathcal{E}_t)$**：
* **实体集合 $\mathcal{V}_t$**：包含区县节点、**14 类标准化灾害概念节点**（`暴雨`, `洪涝`, `台风`, `干旱`, `高温`, `低温`, `雪灾`, `大风`, `冰雹`, `雷电`, `沙尘暴`, `雾霾`, `连阴雨`, `地质灾害`）、高频灾害亚型节点（`disaster_subtype`） 及 **5 类承灾体概念节点**（农作物 `affected_crops`、房屋建筑、学校教育、工业工厂、生命线基础设施）。


* **关系集合 $\mathcal{R}$**：定义 4 类标准时序演化关系：
1. `(区县, 发生灾害, 灾害类型, t)`：由 `start_time` 至 `end_time` 期间的激活记录构建；


2. `(灾害类型A, 级联诱发, 灾害类型B, t)`：若同一区县或相邻区县在 $[t, t+3]$ 天内先后发生灾害 A 与 B（例如 `暴雨` $\rightarrow$ `洪涝` $\rightarrow$ `地质灾害`），且 `weather_summary` 或 `impact_description` 中存在因果共现，则激活该级联边；


3. `(灾害类型, 冲击承灾体, 承灾体类别, t)`：根据非零损失字段（如 `disaster_area > 0`、`collapsed_houses > 0`、`schools_closed > 0`、`factories_stopped > 0`）及文本抽取构建；


4. `(区县, 采取防御响应, 预警与转移级别, t)`：根据 `warning_info`（预警发布情况）与 `relocated`（安置转移人数）构建。

### 三、 大模型离线本构特征提取规程（免昂贵在线微调，单卡可复现）

为了消除在线调用百亿大模型的算力瓶颈并保证 100% 确定性复现，采用 **“冻结开源基座大模型（Qwen2.5-7B-Instruct 或 DeepSeek-R1-Distill-Qwen-7B，设置 `temperature=0.0`）离线提取结构化语义嵌入 + 端到端训练轻量级变分投影网络 $q_{\phi}$”** 的方案：

1. **输入文本组装模板（Prompt Template）**：
对于每个区县 $i$ 在时刻 $t$，拼接两部分文本：


* **实时报告文本 $\mathcal{T}_{i,\le t}^{\text{cur}}$**：当收到 `report_status` 为“初报”或“续报”时，填入 `weather_summary`、`warning_info`、`impact_description` 及 `remarks`（若为灾前无报告阶段，则填 `"当前无灾情直报"`）；


* **历史检索原型文本 $\mathcal{T}_{i,t}^{\text{RAG}}$**：使用 `bge-large-zh-v1.5` 向量模型，以当前区县名、季节与前 3 天气象摘要为 Query，在**训练集**的 `search_text` 字段中检索 Top-3 历史最相似记录的文本摘要。




2. **缓存张量输出**：提取 LLM 最后一层隐藏状态的平均池化向量 $\mathbf{h}_{i,t}^{\text{LLM}} \in \mathbb{R}^{3584}$ 与历史先验向量 $\mathbf{h}_{i,t}^{\text{RAG}} \in \mathbb{R}^{3584}$，保存为 `.pt` 内存映射文件。

### 四、 核心统一模型（PT-GNO）可复现 PyTorch 代码实现

以下提供完整的 **PT-GNO** 模型核心架构代码，严格实现第一性原理下的平流-反应偏常微分算子、LLM 变分本构调制、可微朗道相变门控与变分自由能损失：

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class LLMConstitutiveFunctional(nn.Module):
    """
    大模型摊销变分本构泛函 q_phi(Theta | T):
    将缓存的 LLM 实时/RAG 语义向量映射为物理微分方程的三组局地本构参数:
    1. tau: 致灾相变临界阈值 (B, N, 1)
    2. gamma: 防灾耗散率 (B, N, D)
    3. W_cascade: 14类灾害链级联转移矩阵调制权重 (B, N, 14, 14)
    """
    def __init__(self, llm_dim=3584, hidden_dim=64, num_disasters=14):
        super().__init__()
        self.hidden_dim = hidden_dim
        self.num_disasters = num_disasters
        
        # 变分编码器 (推断均值 mu 与对数方差 logvar)
        self.encoder = nn.Sequential(
            nn.Linear(llm_dim, 256),
            nn.GELU(),
            nn.LayerNorm(256)
        )
        self.fc_mu = nn.Linear(256, hidden_dim)
        self.fc_logvar = nn.Linear(256, hidden_dim)
        
        # 物理本构参数解码头
        self.head_tau = nn.Sequential(nn.Linear(hidden_dim, 1), nn.Softplus()) # 阈值恒正
        self.head_gamma = nn.Sequential(nn.Linear(hidden_dim, hidden_dim), nn.Sigmoid()) # 耗散率 [0, 1]
        self.head_cascade = nn.Linear(hidden_dim, num_disasters * num_disasters)

    def encode(self, h_llm):
        h = self.encoder(h_llm)
        return self.fc_mu(h), self.fc_logvar(h)

    def reparameterize(self, mu, logvar):
        if self.training:
            std = torch.exp(0.5 * logvar)
            eps = torch.randn_like(std)
            return mu + eps * std
        return mu

    def forward(self, h_cur_llm, h_rag_llm):
        # 后验分布 q_phi(Theta | T_cur) 与 历史RAG先验分布 p(Theta | T_RAG)
        mu_post, logvar_post = self.encode(h_cur_llm)
        mu_prior, logvar_prior = self.encode(h_rag_llm)
        
        theta = self.reparameterize(mu_post, logvar_post)
        
        tau = self.head_tau(theta) + 0.5  # 基础相变势垒下界
        gamma = self.head_gamma(theta)
        W_cascade = self.head_cascade(theta).view(*theta.shape[:-1], self.num_disasters, self.num_disasters)
        
        # 计算变分自由能中的 KL 散度项: KL(q_post || p_prior)
        kl_loss = -0.5 * torch.sum(
            1 + (logvar_post - logvar_prior) 
            - ((mu_post - mu_prior).pow(2) + logvar_post.exp()) / (logvar_prior.exp() + 1e-8),
            dim=-1
        ).mean()
        
        return tau, gamma, W_cascade, kl_loss


class PhysicsAdvectionReactionCell(nn.Module):
    """
    统一微分算子核: 跨区县气压-风场平流扩散 (Horizontal PDE) + 垂直气象注入与耗散 (Vertical ODE)
    """
    def __init__(self, meteo_dim=22, hidden_dim=64):
        super().__init__()
        # 局地气象致灾能量注入映射 Psi_in
        self.psi_in = nn.Sequential(
            nn.Linear(meteo_dim, hidden_dim),
            nn.GELU(),
            nn.Linear(hidden_dim, hidden_dim)
        )
        # 跨区县平流传输核参数 (接收 [Delta_PRS, WIN_S_Max_i, WIN_S_10mi_Avg_i])
        self.adv_kernel = nn.Sequential(
            nn.Linear(3, 16),
            nn.GELU(),
            nn.Linear(16, 1),
            nn.Softplus()
        )
        # 初报/续报观测数据同化校准门控 G_assim
        self.assim_gate = nn.GRUCell(hidden_dim, hidden_dim)

    def forward(self, U, x_meteo, prs_wind_feat, adj_mask, gamma, report_obs_emb=None, has_report_mask=None, dt=1.0):
        """
        U: 当前节点致灾潜能状态 (B, N, D)
        x_meteo: 当日22维气象特征 (B, N, 22)
        prs_wind_feat: 节点气压与风速特征 [PRS_Avg, WIN_S_Max, WIN_S_10mi_Avg] (B, N, 3)
        adj_mask: 空间邻接矩阵 (N, N)
        gamma: LLM调制的防灾耗散率 (B, N, D)
        """
        B, N, D = U.shape
        # 1. 计算跨区县气压梯度 Delta_PRS_ij = PRS_j - PRS_i (高压流向低压)
        prs = prs_wind_feat[:, :, 0:1] # (B, N, 1)
        delta_prs = prs.unsqueeze(2) - prs.unsqueeze(1) # (B, N, N, 1)
        wind_src = prs_wind_feat[:, :, 1:3].unsqueeze(1).expand(B, N, N, 2) # (B, N, N, 2)
        
        edge_phys = torch.cat([delta_prs, wind_src], dim=-1) # (B, N, N, 3)
        K_adv = self.adv_kernel(edge_phys).squeeze(-1) * adj_mask.unsqueeze(0) # (B, N, N)
        K_adv = K_adv / (K_adv.sum(dim=-1, keepdim=True) + 1e-6)
        
        # 平流-扩散通量: sum_j K_adv_ij * (U_j - U_i)
        adv_flux = torch.bmm(K_adv, U) - U
        
        # 2. 垂直气象注入项 Psi_in
        energy_in = self.psi_in(x_meteo)
        
        # 3. 欧拉/RK2 积分步更新连续势能场 dU/dt
        dU = adv_flux + energy_in - gamma * U
        U_next = U + dt * dU
        
        # 4. 伴随“初报/续报”的连续时间贝叶斯数据同化跳跃更新
        if report_obs_emb is not None and has_report_mask is not None:
            U_flat = U_next.view(B * N, D)
            obs_flat = report_obs_emb.view(B * N, D)
            U_updated = self.assim_gate(obs_flat, U_flat).view(B, N, D)
            mask = has_report_mask.unsqueeze(-1) # (B, N, 1)
            U_next = mask * U_updated + (1.0 - mask) * U_next
            
        return U_next


class PT_GNO(nn.Module):
    """
    物理引导的相变图神经算子完整主干:
    同时输出: (1) 14类灾害相变激活概率, (2) 灾害链级联矩阵, (3) 5级损失等级 logits, (4) 多维连续损失数值
    """
    def __init__(self, meteo_dim=22, llm_dim=3584, hidden_dim=64, num_disasters=14, num_loss_levels=5, num_cont_losses=6, temp=0.2):
        super().__init__()
        self.hidden_dim = hidden_dim
        self.temp = temp
        self.constitutive_fn = LLMConstitutiveFunctional(llm_dim, hidden_dim, num_disasters)
        self.pde_ode_cell = PhysicsAdvectionReactionCell(meteo_dim, hidden_dim)
        
        # 将潜能向量投影到14类灾害语义子空间
        self.disaster_proj = nn.Linear(hidden_dim, num_disasters)
        
        # 多维灾情损失读出头 Readout
        self.loss_level_head = nn.Linear(hidden_dim + num_disasters, num_loss_levels)
        self.cont_loss_head = nn.Linear(hidden_dim + num_disasters, num_cont_losses)

    def forward(self, x_meteo_seq, prs_wind_seq, h_cur_seq, h_rag_seq, adj_mask):
        """
        序列输入维度: (B, T, N, *)
        """
        B, T, N, _ = x_meteo_seq.shape
        U = torch.zeros(B, N, self.hidden_dim, device=x_meteo_seq.device)
        
        topo_probs_list, level_logits_list, cont_preds_list = [], [], []
        total_kl_loss = 0.0
        
        for t in range(T):
            # 1. LLM 变分泛函推断 t 时刻本构参数
            tau, gamma, W_cascade, kl_t = self.constitutive_fn(h_cur_seq[:, t], h_rag_seq[:, t])
            total_kl_loss = total_kl_loss + kl_t
            
            # 2. 物理平流-反应算子推进潜能状态 U(t)
            U = self.pde_ode_cell(U, x_meteo_seq[:, t], prs_wind_seq[:, t], adj_mask, gamma)
            
            # 3. 可微朗道相变门控 (Landau Phase-Transition Gate)
            energy_norm = torch.norm(U, p=2, dim=-1, keepdim=True) # ||U_i(t)||_2, (B, N, 1)
            phase_gate = torch.sigmoid((energy_norm - tau) / self.temp) # 突破临界阈值 tau 时趋近于 1
            
            # 4. 灾害图谱节点涌现与级联传播
            raw_dis_scores = self.disaster_proj(U) # (B, N, 14)
            cascaded_scores = torch.matmul(W_cascade, raw_dis_scores.unsqueeze(-1)).squeeze(-1)
            A_topo_prob = phase_gate * torch.sigmoid(raw_dis_scores + cascaded_scores) # (B, N, 14)
            
            # 5. 多维灾情损失读出 (分类 + 连续回归)
            joint_state = torch.cat([U, A_topo_prob], dim=-1)
            level_logits = self.loss_level_head(joint_state) # (B, N, 5)
            cont_preds = F.relu(self.cont_loss_head(joint_state)) * phase_gate # 无灾相态下损失严格归零
            
            topo_probs_list.append(A_topo_prob)
            level_logits_list.append(level_logits)
            cont_preds_list.append(cont_preds)
            
        return (
            torch.stack(topo_probs_list, dim=1),
            torch.stack(level_logits_list, dim=1),
            torch.stack(cont_preds_list, dim=1),
            total_kl_loss / T
        )

```

### 五、 训练超参数、目标函数配置与软硬件环境（Reproducibility Checklist）

#### 1. 统一变分自由能损失函数实现细节

对于稀疏灾害相变预测与多维损失回归，式中的负对数似然项 $-\log p_{\theta}(\mathbf{A}_{1:T}, \mathbf{Y}_{1:T}^{\text{loss}} \mid \mathbf{U}_{1:T})$ 具体展开为三个无超参冲突的似然分量之和：

* **拓扑相变似然 $\mathcal{L}_{\text{topo}}$**：针对日常无灾样本多、灾害样本少的稀疏特性，对 14 类 `disaster_type_std` 激活概率采用 **Focal Binary Cross-Entropy**（$\gamma_{\text{focal}}=2.0, \alpha=0.75$）；


* **损失等级似然 $\mathcal{L}_{\text{level}}$**：对 `loss_level`（`无损失:0`, `低:1`, `中:2`, `高:3`, `特大:4`）采用类别频率倒数加权的交叉熵损失；


* **多维连续损失高斯似然 $\mathcal{L}_{\text{cont}}$**：选取 6 个填充率 100% 的核心连续损失字段——经济损失 `economic_loss`（万元）、受灾人数 `affected_population`、倒塌房屋 `collapsed_houses`（间）、受灾面积 `affected_area`（公顷）、成灾面积 `disaster_area`（公顷）、绝收面积 `total_loss_area`（公顷）。由于灾情数值跨度极大，统一作 $\tilde{y} = \log_{10}(1 + y)$ 变换后计算 **Huber Loss**（$\delta=1.0$），且仅在发生灾害的激活节点上反传回归梯度。

### 六、 分步执行与消融控制协议（Step-by-Step Execution Protocol）

1. **Step 1（对齐与特征落盘，预计耗时 2 小时）**：
运行 `clean_disaster_records` 读取 `disaster_records_unified.parquet`，补全缺失区县并与地面气象表按 `(Province, City, Cnty, Year, Mon, Day)` 左连接对齐，生成三大区域数据集的张量文件 `SW_Cascade.pt`、`SE_Typhoon.pt`、`North_Agro.pt`。


2. **Step 2（离线提取 LLM 语义与 RAG 先验，预计耗时 3–4 小时 / 单张 RTX 4090 或 A100）**：
遍历所有灾害事件窗口内的文本字段（`weather_summary`, `warning_info`, `impact_description`）与 `search_text`，提取并缓存 $\mathbf{h}_{\text{cur}}^{\text{LLM}}$ 与 $\mathbf{h}_{\text{RAG}}^{\text{LLM}}$。


3. **Step 3（主实验与“初报-续报-终报”同化评测）**：
* 在测试集上分别评估 $\Delta t \in \{1, 3, 5, 7\}$ 天的灾害类型相变预测（Macro-F1, AUPRC, Hits@3）与损失回归（$\log$-MAE, $\log$-RMSE, $R^2$）。


* 筛选测试集中包含完整 `初报` $\rightarrow$ `续报` $\rightarrow$ `终报` 链条（`report_status`）的样本子集，分别在 $t_0$（仅气象）、$t_1$（注入初报）、$t_2$（注入续报）三个时点触发 `PhysicsAdvectionReactionCell` 中的 `assim_gate` 同化门控，记录预测误差随报告演进的衰减曲线。




4. **Step 4（四项受控消融实验一键切换开关）**：
* **消融 1（去除相变门控）**：在代码中令 `phase_gate = 1.0` 恒成立，测试普通连续网络在稀疏灾害突变上的虚警率。
* **消融 2（去除物理平流核）**：将 `K_adv` 替换为标准的参数化图注意力（GAT），屏蔽 `PRS_Avg` 与 `WIN_S_Max` 物理公式。


* **消融 3（去除 LLM 本构调制）**：将 `tau` 和 `gamma` 设为 `nn.Parameter` 静态可学习向量，不传入 `h_cur_seq` 与 `h_rag_seq`。


* **消融 4（构造 Stitched-GNN-LLM 缝合基线）**：并行运行一个标准 GCN 与一个 MLP（输入 LLM 向量），在末端直接拼接两者的输出向量 `torch.cat([h_gcn, h_llm], dim=-1)` 并额外加上有限差分残差 Loss，在同等参数量（约 1.8M 可训练参数）下对比训练收敛曲线与测试集精度。
